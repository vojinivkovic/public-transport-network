# Public Transport Network

A C++ implementation of a **public transport network model and simulator** supporting network queries, route finding, and statistics.

## Features

- Representation of stations and bus lines
- Public transport network management
- Route finding between stations
- Shortest-route search
- Minimum bus-change route search
- Station and bus-line information
- Bus-line statistics
- Strategy-based operations

## C++ Design

- Encapsulation and object-oriented design
- Inheritance and polymorphism
- Strategy pattern
- Dynamic memory management
- Copy and move semantics

## Academic Context

Developed as part of university coursework.

## Technologies

- C++
- Object-oriented programming
- Design patterns
